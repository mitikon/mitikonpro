# 論文準拠 PCA SUB 実装仕様

対象論文：中川慧ほか「部分空間正則化付き主成分分析を用いた日米業種リードラグ投資戦略」SIG-FIN-036-13（2026）。

## 固定する実験条件

- 米国11業種ETFの当日 Close-to-Close リターンを入力する。
- 翌営業日の日本TOPIX-17業種ETFの Open-to-Close リターンで評価する。
- 推定窓 `L=60`、主成分数 `K=3`、上下位比率 `q=0.3` とする。
- 正則化は論文の式(13)どおり `Creg = 0.1 Ct + 0.9 C0` とする。
- 事前部分空間はグローバル、国別スプレッド、景気循環・ディフェンシブの3方向から作る。
- 長期事前相関の標本期間は2010-01-01から2014-12-31までとし、検証期間と重複させない。

## 予測

結合相関行列の上位3固有ベクトルを米国部分 `V_U` と日本部分 `V_J` に分割する。当日米国標準化リターン `z_U,t` から

```text
f_t = V_U.T z_U,t
z_hat_J,t+1 = V_J f_t
B = V_J V_U.T
```

を計算する。予測値上位5業種を各 `+1/5`、下位5業種を各 `-1/5` とし、ネット0、グロス2のポートフォリオを作る。

## 未来情報防止

- 時点`t`のモデルは`t-60`から`t-1`だけで推定する。
- 米国`t`の確定終値を受け取った後、日本`t+1`の寄付前に予測を固定する。
- 長期事前標本は最初の評価シグナル日より前に終了させる。
- 固定済みスコアを後日のデータで変更しないことを自動テストする。

## 実データ再現前に解決する事項

- XLCは2018年設定であり、論文の長期事前期間（2010〜2014年）に実データが存在しない。代替系列または論文著者の補完方法を明示せずに埋めない。
- 無料配信データの調整済みOpen/Closeが論文データと同一か照合する。
- 論文のグロス成績と、取引コスト控除後のネット成績を分けて報告する。

既存の3クラス分類器は比較用ベースラインとして残し、論文準拠PCA SUBの成績には混ぜない。
